# B200 选作题

这些题专门练习 B200 相关能力，不是 GB10 或 4090D 的必做内容。拿到 B200 之前，可以先写设计、接口、伪代码和验收标准；不要把网上的数字当成实测。

- B01：确认设备、Toolkit 和目标架构能编译最小程序。
- B02：用 TMEM 保存和交换矩阵片段，比较它与 shared memory 的职责。
- B03：实现单 CTA 的 MMA/GEMM，检查输入布局、累加精度和边界。
- B04：把数据搬运、计算和同步排成 pipeline，测 1/2/3 阶段。
- B05：实现 persistent kernel，解释为什么 block 不立即退出。
- B06：尝试 2-CTA 协作，记录额外同步和适用形状。
- B07：比较 FP8/FP4 等低精度 GEMM 的速度、误差和缩放策略。
- B08：实现 FA4/相关 attention 路径，并与 M15 的基础版本比较。

每题都要先有可运行的 baseline；若硬件或工具链不满足条件，报告中明确写“未实测”和阻塞原因。
