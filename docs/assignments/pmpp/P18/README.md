# P18：粒子二维空间分桶与邻域查询

## 你要学会什么

用空间桶把相近粒子聚集起来，减少邻域查询的候选数量。把 P09/P11/P17 的计数、偏移与重排连接为一个完整不规则算法。

## 开始前

前置：P09、P11、P17。阅读 PMPP 中关于空间划分、直方图、scan 和邻域访问的主题，按所用版本目录定位，不假定章节号一致。遵循 [统一实验与教学规则](../RULES.md)。

4090D 使用 cuda-sm89，GB10 未运行写“未测”。本机没有 CUDA 时先做接口、CPU reference、手算测试和报告草稿；GPU 部分在服务器验证。工具不可用如实标记，性能结论可用计算量/访存分析辅助，不伪造 profiler 数据。

### 输入输出与边界

float 二维坐标位于 [0,Lx)×[0,Ly)，半径 r>0，桶边长先取 r；右上边界不包含，越界坐标拒绝，不做周期边界。输出每粒子距离平方 <=r^2 的其他粒子数量，不计自身；重复坐标算不同粒子。空输入输出空。

### 创建或修改的文件

- benchmarks/p18/spatial.h：接口与合同。
- benchmarks/p18/spatial_cpu.cpp：CPU reference。
- benchmarks/p18/spatial.cu：GPU baseline 与本题优化版。
- benchmarks/p18/test.cpp、bench.cpp：独立测试与测速入口。
- benchmarks/CMakeLists.txt、tests/CMakeLists.txt：只显式加入实际完成的文件与测试，复用统计库。
- reports/p18.md 和 reports/results/p18/：报告与原始日志。

## 按步骤完成

1. 写 CPU O(n^2) 邻域参考，手算桶边界和两点恰好相距 r 的样本。
2. 写 GPU 全对比较基线用于小规模校验，分阶段实现桶 ID、计数、exclusive scan 偏移和重排粒子 ID。
3. 基于桶访问周围 3×3 桶，再按精确距离过滤；不要只凭同桶认为是邻居。输出保持原粒子 ID 顺序。
4. 验证空、单粒子、重复位置、边缘桶、跨桶近邻、随机；检查总桶计数为 n、重排 ID 是完整排列。
5. n=256/1024/4096 时与全对版比较；n=65536 的优化版测均匀分布与90%聚团。一次只改桶边长；选做 r/2 时需重新推导邻居桶范围。

先完成第一步交由指导者检查，再推进后续；本题不提供完整实现。保留基线，每次优化只改变一个变量。

### 运行与保存输出

以下是计划目标 p18_test 和 p18_bench 的复现命令；对应文件和 CMake target 实现后才能运行，当前不自动加入构建。CPU 阶段先用 cpu-debug 构建 CPU 测试，GPU 阶段独立启用 CUDA 和 GPU 测试。

```bash
cmake --preset cuda-sm89
cmake --build --preset cuda-sm89 --target p18_test p18_bench --parallel
mkdir -p reports/results/p18
set -o pipefail
./build/cuda-sm89/bin/p18_test | tee reports/results/p18/tests.txt
./build/cuda-sm89/bin/p18_bench | tee reports/results/p18/bench.txt
```

### 计时与指标

默认预热 20 次、正式测量 100 次，记录最小和中位耗时，统计方式沿用 nearest-rank。GPU 用 CUDA Event；主机工作或完整流水线需要另列 CPU 单调时钟结果。执行前恢复的状态、哪些阶段计时及哪些阶段排除，必须写入报告。

报告建桶、邻域和全流程 ms，以及实际候选检查次数/粒子；完整算法包含重排与 scan。整数邻居数量精确比较。

## CUDA 工具练习

按 [工具练习路线](../TOOLING.md) 学习命令、编译方式和指标解释。先正确性，再整体时间线，最后按问题采集单 kernel；普通 benchmark 与工具运行分开。

1. 用 nsys/NVTX 分开桶 ID、计数、scan、重排、查询，比较均匀与聚团的阶段分布。
2. ncu 分析密集桶查询的调度/访存，memcheck 检查桶边界和输出；同时记录候选检查次数，解释算法量与实际时间。

交付：在本题报告列工具版本、实际命令、配置、报告/日志路径、观察事实和下一步假设。工具可用时完成本节是练习验收的一部分；不可用则保存错误和采集方案，指标写未测，不阻塞其他可完成阶段。新工具练习不追溯否定 P01 已完成状态，P21/PA 仍为选做。


## 完成标准

- 桶计数/偏移/重排不丢粒子，邻居计数与 CPU 一致。
- 边界、重复位置和跨桶样本正确。
- 聚团输入也测试，不声称分桶总是线性。
- 有独立正确性测试、完整环境与命令、原始日志；报告区分实测、规格和推测。未运行的设备或工具明确注明。

## 常见问题

- 桶边长改小却仍只查 3×3 桶。
- 高密度桶使用固定容量而溢出：用 scan 偏移分配。
- 只测邻域阶段忽略建桶成本。
