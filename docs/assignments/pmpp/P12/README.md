# P12：两个有序数组的并行合并

## 你要学会什么

将两个有序数组合成一个有序输出，练习按输出区间划分任务。co-ranking 是由输出位置确定两个输入各贡献多少元素的方法，重点是边界和重复值。

## 开始前

前置：P11。阅读 PMPP 中关于并行合并、co-ranking 和负载划分的主题，按所用版本目录定位，不假定章节号一致。遵循 [统一实验与教学规则](../RULES.md)。

4090D 使用 cuda-sm89，GB10 未运行写“未测”。本机没有 CUDA 时先做接口、CPU reference、手算测试和报告草稿；GPU 部分在服务器验证。工具不可用如实标记，性能结论可用计算量/访存分析辅助，不伪造 profiler 数据。

### 输入输出与边界

输入为升序 int32，输出容量 m+n；相等时 A 在 B 前，附带来源/原下标标签测试稳定性。输入输出不重叠，m 或 n 为 0 时复制另一数组，两者空时返回。

### 创建或修改的文件

- benchmarks/p12/merge.h：接口与合同。
- benchmarks/p12/merge_cpu.cpp：CPU reference。
- benchmarks/p12/merge.cu：GPU baseline 与本题优化版。
- benchmarks/p12/test.cpp、bench.cpp：独立测试与测速入口。
- benchmarks/CMakeLists.txt、tests/CMakeLists.txt：只显式加入实际完成的文件与测试，复用统计库。
- reports/p12.md 和 reports/results/p12/：报告与原始日志。

## 按步骤完成

1. 写 CPU 稳定合并，用带标签的小数组手算相等值的次序。
2. 先实现每个任务负责一段输出的直白 GPU 版本，自己设计分区定位方法并证明区间不重叠。
3. 实现 co-ranking 或等价的二分分区：由输出区间端点定位 A/B 输入端点，块内合并。
4. 测试双空、单空、重复值、全部 A 小于 B、交错值、极不平衡长度 (1,1000)、(1000,1)、(257,513)。
5. 测总输出 2^20、2^24，长度比 1:1、1:16、1:1024，比较每线程/任务输出粒度 32、128、512。

先完成第一步交由指导者检查，再推进后续；本题不提供完整实现。保留基线，每次优化只改变一个变量。

### 运行与保存输出

以下是计划目标 p12_test 和 p12_bench 的复现命令；对应文件和 CMake target 实现后才能运行，当前不自动加入构建。CPU 阶段先用 cpu-debug 构建 CPU 测试，GPU 阶段独立启用 CUDA 和 GPU 测试。

```bash
cmake --preset cuda-sm89
cmake --build --preset cuda-sm89 --target p12_test p12_bench --parallel
mkdir -p reports/results/p12
set -o pipefail
./build/cuda-sm89/bin/p12_test | tee reports/results/p12/tests.txt
./build/cuda-sm89/bin/p12_bench | tee reports/results/p12/bench.txt
```

### 计时与指标

默认预热 20 次、正式测量 100 次，记录最小和中位耗时，统计方式沿用 nearest-rank。GPU 用 CUDA Event；主机工作或完整流水线需要另列 CPU 单调时钟结果。执行前恢复的状态、哪些阶段计时及哪些阶段排除，必须写入报告。

报告 ms、输出元素/s；对无标签 int32 性能版可按一次读取加一次写入的 2*(m+n)*4 字节给算法带宽，二分额外读取不含在该估算中。

## 完成标准

- 输出有序、长度正确、每个输入元素恰好出现一次，标签验证稳定性。
- 空数组和重复键的二分边界正确。
- 报告分区图和负载不平衡实验。
- 有独立正确性测试、完整环境与命令、原始日志；报告区分实测、规格和推测。未运行的设备或工具明确注明。

## 常见问题

- 相等值的 <= 与 < 规则不一致：可能重复或漏元素。
- 按输入等分导致输出任务不均衡。
- 只检查有序，不检查元素是否丢失。
