# Modern GPU 作业

这组题不是让你背 TMA、TIRx、CLC 等缩写，而是让你用一个小实验理解它们解决的实际问题。完整题目在 [学习计划](../../LEARNING_PROJECT_PLAN.md) 的 M01–M15。

做每一题时先写三句话：

1. 这项硬件或软件机制解决什么问题？
2. 我能写哪个最小实验观察它？
3. 我的 GB10 或 4090D 是否支持它？如果不支持，替代实验是什么？

GB10 和 4090D 不要强行使用同一套最佳参数。记录输入形状、数据类型、编译目标和误差，再比较结果。TIRx、PyTorch、TVM 等依赖按题目需要再安装，初始工程不会自动下载。
